Operaton is developed as an open source project in collaboration with the community. Operaton does not have separate editions; the product is open source.

## Extensions

Operaton supports the community in its effort to build additional extensions. Such community extensions are maintained by the community and are not part of the official Operaton distribution.

The [Operaton Hub](https://operaton.org/hub/) is the central place to discover Operaton-related resources, including solutions, plugins, add-ons and tools. Each extension lives in its own repository, maintained by its authors, and the Hub lists them with their type and license.

### Building an Extension

Do you have a great idea around open source BPM you want to share with the world? Awesome! Build your extension in a repository of your own, and [request an entry on the Operaton Hub](https://github.com/operaton/operaton.org/issues/new?template=request-hub-entry.yml) to make it discoverable by others.

Note that extensions built for Camunda 7 are not automatically compatible with Operaton, so check the compatibility of an extension before using it.

You can also learn about [contributing code to the core Operaton codebase](https://github.com/operaton/operaton/blob/main/CONTRIBUTING.md).
